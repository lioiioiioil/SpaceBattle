# SpaceBattle

Учебная локальная игра для двух игроков на одной клавиатуре. Два корабля перемещаются по полю, поворачиваются и стреляют друг в друга. Проект написан на Java с использованием Swing и AWT, без сторонних библиотек.

## Требования

- JDK 17 или новее (`java -version` и `javac -version`). Используется `Random.nextInt(origin, bound)`, поэтому старые JDK не подходят.
- Графическая среда рабочего стола: игра открывает окно Swing и не работает в headless-режиме.
- Все PNG из `src/` должны оставаться на месте. Игра читает их по относительным путям из корня репозитория.
- `make` нужен только для команд Makefile; ниже приведены команды без него.

## Сборка и запуск

Из корня репозитория на Linux или macOS:

```bash
make build
make run
```

`make build` компилирует все классы в `build/classes`, `make run` пересобирает проект и запускает `Main`. Для удаления результатов сборки используйте `make clean`.

Эквивалент без make (Bash, Linux/macOS):

```bash
mkdir -p build/classes
javac --release 17 -encoding UTF-8 -d build/classes src/*.java
java -cp build/classes Main
```

В PowerShell:

```powershell
New-Item -ItemType Directory -Force build/classes | Out-Null
javac --release 17 -encoding UTF-8 -d build/classes (Get-ChildItem src/*.java).FullName
java -cp build/classes Main
```

В IDE выберите JDK 17+, назначьте `src/` каталогом исходников, точкой входа — `Main`, а рабочим каталогом — корень репозитория. При ошибке чтения изображений проверьте рабочий каталог и наличие PNG. После запуска щёлкните игровое поле, если клавиатура не получает фокус.

## Управление

| Действие | Первый корабль | Второй корабль |
| --- | --- | --- |
| Движение вперёд / назад | Стрелки вверх / вниз | W / S |
| Поворот влево / вправо | Стрелки влево / вправо | A / D |
| Выстрел | Enter | Space |

У каждого корабля 100 HP. Первый бластер наносит 10 единиц урона; тяжёлый бластер второго корабля наносит 100 с задержкой 700 мс. После уничтожения корабля отображается взрыв, таймер игры останавливается. Для нового раунда закройте окно и запустите игру заново.

## Устройство проекта

```text
src/Main.java         # точка входа
src/GameFrame.java    # окно Swing
src/GamePanel.java    # таймер, клавиатура, столкновения и отрисовка
src/Ship.java         # движение корабля и здоровье
src/Weapon.java       # список снарядов и базовое оружие
src/Blaster.java      # обычный бластер
src/BigBlaster.java   # тяжёлый бластер с задержкой
src/Bullet.java       # движение и урон снаряда
src/*.png             # фон, корабли, снаряды и взрыв
```

Это прототип: размер окна задан в `Main` (2000 × 2000), границы движения в `Ship` заданы отдельно (1400 × 750). Масштабирования под экран, меню, перезапуска раунда и сетевой игры пока нет. Управление следует событийной модели клавиатуры Swing; темп стрельбы зависит в том числе от автоповтора клавиш.

## Проверка

GitHub Actions собирает исходники на JDK 17 командой `make build`. Проверка компиляции не запускает окно и не подтверждает игровой процесс. Автоматических игровых тестов пока нет; запуск требует рабочего стола и ресурсов из `src/`.
